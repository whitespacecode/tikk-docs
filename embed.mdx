The embed widget puts your booking page on your own website. Visitors browse your services, pick a slot and book without leaving your site.

You can add it in three ways. All three use the same script tag, with `data-domain` set to your username.

## Inline embed

Drop this where you want the booking page to appear. Replace `yourname` with your username.

```html
<script async src="https://embed.tikk.chat" data-domain="yourname"></script>
```

The widget renders at that exact spot and resizes itself to fit its content, so it works inside a landing page section, a contact page or a sidebar.

## Inline link

Renders a link or button in the flow of your page. Clicking it opens your booking page in a pop-up over the current page.

```html
<script
  async
  src="https://embed.tikk.chat"
  data-domain="yourname"
  data-type="button-link"
  data-buttontext="Schedule a meeting"
  data-buttoncolor="#000000"
></script>
```

Leave `data-buttoncolor` out and you get an underlined text link that inherits your site's font and colour. Include it and you get a solid button in that colour, with the label colour picked automatically for contrast.

## Floating button

Renders a pill-shaped button pinned to one corner of the viewport, on top of your page. Place the snippet once, anywhere in the `<body>`.

```html
<script
  async
  src="https://embed.tikk.chat"
  data-domain="yourname"
  data-type="button-floating"
  data-buttontext="Schedule a meeting"
  data-buttoncolor="#000000"
  data-buttonposition="bottomRight"
></script>
```

## Attributes

| Attribute             | Applies to        | Values                                             | Default                                        |
| --------------------- | ----------------- | -------------------------------------------------- | ---------------------------------------------- |
| `data-domain`         | All               | Your username. **Required.**                       | —                                              |
| `data-type`           | All               | `inline`, `button-link`, `button-floating`         | `inline`                                       |
| `data-buttontext`     | Both button types | Any label                                          | `Schedule a meeting`                           |
| `data-buttoncolor`    | Both button types | Hex colour, e.g. `#1a1a1a`                         | Text link (inline link) / `#000000` (floating) |
| `data-buttonicon`     | Both button types | `none`, `tikk`, `calendar`, `clock`                | `none`                                         |
| `data-buttonposition` | Floating button   | `bottomRight`, `bottomLeft`, `topRight`, `topLeft` | `bottomRight`                                  |
| `data-content`        | All               | `minimal` hides the host panel (photo, name, bio)  | Host panel shown                               |

<Note>
  On the Free plan the button always carries the Tikk icon, whatever
  `data-buttonicon` says. Customising the icon is a Pro feature and the check
  happens on Tikk's side, so editing the attribute won't change it.
</Note>

Use `data-content="minimal"` when the surrounding page already introduces you and repeating your photo and bio inside the widget would be redundant:

```html
<script
  async
  src="https://embed.tikk.chat"
  data-domain="yourname"
  data-content="minimal"
></script>
```

## No-script alternative

Some site builders strip `<script>` tags. Notion, Webflow and similar tools accept a plain iframe instead:

```html
<iframe
  src="https://tikk.chat/yourname?embed=1"
  width="100%"
  height="700"
  frameborder="0"
></iframe>
```

The script version is preferable where you can use it, because it resizes itself to its content. A plain iframe keeps whatever height you give it.

<Note>
  Your username is the handle in your booking URL (`tikk.chat/yourname`). Set it
  under **Settings → Profile**; it's shown in the header of the **Website** screen.
</Note>
