The Tikk API is a REST API for your own data. Your public profile and services, your available time slots, the bookings people have made with you and your single-use links. Reading is the default. Writing is limited to your services: create, edit and delete. Every endpoint responds with JSON and requires a valid bearer token. No public, unauthenticated routes.

## Base URL

All requests go to the following base URL:

```text
https://app.tikk.chat/api/v1
```

## Key characteristics

- All responses are JSON
- All timestamps are ISO 8601 in UTC
- Every request must include a bearer token in the `Authorization` header
- Rate limit: 60 requests per minute per credential

<Tip>
  Building an app that other Tikk users connect to? Register it and follow the
  OAuth guide in the [developer portal](https://developer.tikk.chat).
</Tip>
