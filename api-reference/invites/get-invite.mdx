---
title: "GET /invites/{id}. Retrieve a single-use link"
sidebarTitle: "GET /invites/{id}"
description: "Fetch one single-use booking link by id, with its URL, status, contact, durations and expiry."
---

The `/invites/{id}` endpoint returns one single-use link. An id that doesn't belong to your account returns `404`.

## Endpoint

```text
GET https://app.tikk.chat/api/v1/invites/{id}
```

**Required scope:** `invites.read`

## Path parameters

<ParamField path="id" type="integer" required>
  The link's `id`, from `POST /invites` or `GET /invites`.
</ParamField>

## Example request

```bash
curl https://app.tikk.chat/api/v1/invites/73920 \
  -H "Authorization: Bearer {YOUR_API_KEY}"
```

## Response schema

<ResponseField name="data" type="object">
  The matching Invite object.

  <Expandable title="Invite">
    <ResponseField name="id" type="integer">
      Unique identifier of the link.
    </ResponseField>

    <ResponseField name="title" type="string">
      Name of the link.
    </ResponseField>

    <ResponseField name="description" type="string | null">
      Note shown at the top of the booking page.
    </ResponseField>

    <ResponseField name="status" type="string">
      One of `open`, `used`, `expired` or `disabled`. A used link stays `used` even if it later expires or is switched off.
    </ResponseField>

    <ResponseField name="url" type="string | null">
      The private link to send. `null` until you pick a username.
    </ResponseField>

    <ResponseField name="contact" type="object | null">
      Who the link is for. `null` when no contact was given.

      <Expandable title="contact fields">
        <ResponseField name="name" type="string | null">
          Contact name.
        </ResponseField>

        <ResponseField name="email" type="string | null">
          Contact email address.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="durations" type="array">
      Offered durations in minutes, for example `[30]`.
    </ResponseField>

    <ResponseField name="expires_at" type="string (date-time) | null">
      When the link stops working, ISO 8601.
    </ResponseField>

    <ResponseField name="created_at" type="string (date-time) | null">
      When the link was created, ISO 8601.
    </ResponseField>
  </Expandable>
</ResponseField>

| `status`   | Meaning                                           |
| ---------- | ------------------------------------------------- |
| `open`     | Can be booked.                                    |
| `used`     | Booked. The link no longer works.                 |
| `expired`  | Past `expires_at` without a booking.              |
| `disabled` | Switched off in Tikk.                             |

## Example response

```json
{
  "data": {
    "id": 73920,
    "title": "Intro call for Sam",
    "description": null,
    "status": "open",
    "url": "https://tikk.chat/jane/Xk3pQ9aB2c/intro-call-for-sam",
    "contact": { "name": "Sam Smith", "email": "sam@example.com" },
    "durations": [30],
    "expires_at": "2026-10-31T09:00:00+00:00",
    "created_at": "2026-10-01T09:00:00+00:00"
  }
}
```

## Errors

| Status | Meaning                                                                                         |
| ------ | ----------------------------------------------------------------------------------------------- |
| `401`  | Missing or invalid credential.                                                                  |
| `403`  | Your credential does not have the `invites.read` scope.                                         |
| `404`  | No link with this id on your account.                                                           |
| `429`  | Rate limit exceeded. Back off and retry after the period indicated in the `Retry-After` header. |
