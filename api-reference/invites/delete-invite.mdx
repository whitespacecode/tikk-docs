---
title: "DELETE /invites/{id}. Delete an unbooked link"
sidebarTitle: "DELETE /invites/{id}"
description: "Delete a single-use link that hasn't been booked. Booked links return 409 and stay."
---

The `DELETE /invites/{id}` endpoint removes a link that hasn't been booked. A booked link can't be deleted: it's the booking's record of how it was made.

## Endpoint

```text
DELETE https://app.tikk.chat/api/v1/invites/{id}
```

**Required scope:** `invites.write`

## Path parameters

<ParamField path="id" type="integer" required>
  The link's `id`.
</ParamField>

## Example request

```bash
curl -X DELETE https://app.tikk.chat/api/v1/invites/73920 \
  -H "Authorization: Bearer {YOUR_API_KEY}"
```

## Response

Status `204 No Content` with an empty body.

## Errors

| Status | Meaning                                                                                         |
| ------ | ----------------------------------------------------------------------------------------------- |
| `401`  | Missing or invalid credential.                                                                  |
| `403`  | Your credential does not have the `invites.write` scope.                                        |
| `404`  | No link with this id on your account.                                                           |
| `409`  | The link has been booked and can't be deleted.                                                  |
| `429`  | Rate limit exceeded. Back off and retry after the period indicated in the `Retry-After` header. |
