---
title: "POST /invites. Create a single-use link"
sidebarTitle: "POST /invites"
description: "Create a private booking link for one person, copied from a service or built standalone. Returns the link with status 201."
---

The `POST /invites` endpoint creates a single-use link and returns it. Send the person its `url`. You can copy an existing service or create a standalone link with a title and duration.

Custom hours, location and booking window aren't available through the API. Set those in Tikk.

## Endpoint

```text
POST https://app.tikk.chat/api/v1/invites
```

**Required scope:** `invites.write`

## Body parameters

<ParamField body="service" type="string">
  Slug of one of your active services to copy. The link offers that service's
  durations and location. Can't be combined with `duration`. Unknown slugs
  return `422`.
</ParamField>

<ParamField body="title" type="string">
  Name of the link, at most 50 characters. Required without `service`. With
  `service` it replaces the default title, "{service} for {contact_name}".
</ParamField>

<ParamField body="description" type="string">
  Note shown at the top of the booking page, at most 500 characters.
</ParamField>

<ParamField body="contact_name" type="string">
  Who the link is for, at most 100 characters.
</ParamField>

<ParamField body="contact_email" type="string">
  Email address of the contact. When given, the contact is saved to your
  contacts.
</ParamField>

<ParamField body="expires_in_days" type="integer">
  Days until the link expires. Between `1` and `365`. Defaults to `30`.
</ParamField>

<ParamField body="duration" type="integer">
  Meeting length in minutes, between `5` and `480`. Defaults to `30`. Only
  without `service`.
</ParamField>

## Example request

```bash
curl -X POST https://app.tikk.chat/api/v1/invites \
  -H "Authorization: Bearer {YOUR_API_KEY}" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"service": "intro-call", "contact_name": "Sam Smith", "contact_email": "sam@example.com"}'
```

## Response

Status `201 Created`. The body is `{ "data": ... }` with the Invite object described on [Get invite](/api-reference/invites/get-invite#response-schema).

```json
{
  "data": {
    "id": 73920,
    "title": "Intro call for Sam Smith",
    "description": null,
    "status": "open",
    "url": "https://tikk.chat/jane/Xk3pQ9aB2c/intro-call-for-sam-smith",
    "contact": { "name": "Sam Smith", "email": "sam@example.com" },
    "durations": [30, 60],
    "expires_at": "2026-10-31T09:00:00+00:00",
    "created_at": "2026-10-01T09:00:00+00:00"
  }
}
```

## Errors

| Status | Meaning                                                                                               |
| ------ | ----------------------------------------------------------------------------------------------------- |
| `401`  | Missing or invalid credential.                                                                        |
| `403`  | Your credential does not have the `invites.write` scope.                                              |
| `422`  | A field failed validation, for example no `title` without `service` or both `service` and `duration`. |
| `429`  | Rate limit exceeded. Back off and retry after the period indicated in the `Retry-After` header.       |
